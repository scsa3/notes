Flexus Sound System

相容與擴充規則

所有 Core 都能逐步增加低頻與環繞，但數量和接線方式有明確限制。

所有 Core 都可擴充

Core 100、200、300 都能連接 Sub 100 或 Sub 200，也能連接一組 Surr 100 或 Surr 200。選 Soundbar 時可以先看本體聲道與功能，不必擔心之後被鎖在單一尺寸的 Sub 或 Surr。

最多兩顆無線 Sub

每套 Flexus 可同時連接最多兩顆無線 Sub，以及一組無線 Surr。Klipsch 建議雙低音使用相同型號，以不同擺位改善房間中的峰值與凹陷；增加第二顆不代表低頻下限會自動降低。

一個 Transport 接收器

Sub 和 Surr 隨附預先配對的 Flexus Transport USB 接收器，但 Core 只有一個接收器連接位置。同時使用 Sub 與 Surr 時，其中一組透過接收器連線，其餘元件需依官方流程手動配對到同一系統。

無線不等於免電源

Sub 需要接牆上電源；Surr 100 與 Surr 200 的左右喇叭也各自需要一個插座。規劃後環繞位置時，仍要先確認沙發兩側或後牆附近有安全、可隱藏的供電方式。

怎麼組？

最精簡的電視升級

Core 100 寬度只有 71.1 公分，適合小型電視櫃與空間有限的房間。它能解碼 Atmos，但使用虛擬化而非實體上向單體；若主要問題是對白與基本低頻，先單獨使用即可。

主流完整劇院

Core 200 已有獨立中央聲道與兩個上向高度聲道。優先加入一顆 Sub 100／200 可提升電影低頻，再加入 Surr 100 建立實體後環繞；若希望後方也有高度反射，再選 Surr 200。

功能最完整的核心

Core 300 適合較寬電視櫃，加入側向單體、DTS:X、HDMI 2.1 輸入、網路串流與 Dirac Live。它能校正房間，但不代表可以省略正確擺位；若加入 Sub 與 Surr，完成配對後應重新執行校正。

Sub 100 或 Sub 200

Sub 100 的功率與箱體數據完整，體積也較小。Sub 200 有 12 吋單體與更大的密閉箱體，但官方現行數據不足以證明更深或更大聲；購買前應參考實測、實際試聽與所在地區價格，而不是只看口徑。

Flexus 的優勢是少接線、可逐步擴充；限制則是 Core 決定了處理、輸入與前方聲道架構，無法像 AVR 系統任意更換單一聲道。若目標是自由搭配喇叭、精確調整分頻或長期升級，仍應和傳統 AVR 被動式系統一起比較。
